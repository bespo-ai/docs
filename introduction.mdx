Script.it is an AI-powered automation platform that lets you describe what you want to automate in plain English and have a working workflow built and running in minutes. You don't need to write code, wire up logic blocks, or manage infrastructure — you just tell the AI agent what you need.

## How it works

Every automation on Script.it follows the same pattern:

1. **Describe** — you type what you want to automate in the chat interface.
2. **The agent builds** — Script.it's AI agent creates a script (a YAML workflow definition) with the right steps and code.
3. **Runs in a sandbox** — scripts execute in an isolated environment, so your automation runs safely without affecting anything else.
4. **Connects your tools** — scripts can read from and write to 600\+ integrations including Slack, Gmail, Notion, HubSpot, and more.

## Why Script.it

Most automation tools make you choose between rigid visual builders that break when your needs change, or fully autonomous AI agents that are hard to inspect or control. Script.it sits between these extremes: the AI does the heavy lifting, but every workflow is a readable script you can review, edit, and reuse.

## Key concepts

Here's a quick overview of the building blocks you'll encounter:

- **Scripts** — Workflow definitions, each containing one or more blocks.
- **Blocks** — the individual steps in a script. Each block runs a piece of code (Python or shell) or contains documentation.
- **Sessions** — chat conversations with the AI agent, each with its own isolated working directory.
- **Triggers** — rules that run a script automatically on a schedule, via webhook, or in response to an integration event.
- **Integrations** — connected third-party services that your scripts can interact with.
- **Credits** — the usage-based currency that tracks AI and execution costs.
